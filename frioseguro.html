// EL PROBLEMA

Cuando el camión desaparece del radar

Los vehículos del ISEM recorren rutas donde la cobertura celular es inexistente. Los sistemas convencionales asumen conectividad permanente.

"Durante las 2–3 horas que el transporte pasa incomunicado en la sierra, las vacunas sufren un choque térmico invisible."

Para cuando el camión recupera señal, el daño ya es irreversible. Sin registro continuo, el lote se aplica como si estuviera en perfecto estado.

ESCENARIO — TOLUCA → SULTEPEC
06:00 — Salida centralOnline. Temp: 4.2°C. GPS activo.
08:30 — Zona marginal⚡ Sin señal. Sistema pierde el rastro.
09:15 — Falla refrigeración🌡 Temp sube a 14°C. Nadie lo sabe.
11:00 — Señal recuperadaFríoSeguro sincroniza 147 registros. Alerta georreferenciada ✓
// SOLUCIÓN

Tres pilares de resiliencia

Arquitectura Offline-First diseñada para las condiciones del territorio mexiquense.

Almacenamiento Offline

Cola local SQLite. Cada lectura se guarda con timestamp real independiente de conectividad. Zero data loss garantizado.

Telemetría Térmica

Monitoreo continuo de temperatura y puerta. Algoritmo de degradación evalúa retroactivamente si el lote superó umbrales.

Georreferenciación

Leaflet + OpenStreetMap: verde online, naranja punteado offline. Marcador exacto de la anomalía térmica.

// METODOLOGÍA

4 fases de operación

FASE 01

Simulación de cobertura

Wokwi/Tinkercad + MODO_RURAL corta HTTP y mantiene lectura a JSON local.

FASE 02

Backend reconciliación

PHP 8.3 procesa batch histórico y evalúa algoritmo de degradación térmica.

FASE 03

Mapa de cobertura

Bootstrap 5.3: línea verde (online) y punteada naranja/roja (offline).

FASE 04

Puntos críticos

Leaflet.js renderiza marcadores ⚠ en coordenadas exactas de la anomalía.
